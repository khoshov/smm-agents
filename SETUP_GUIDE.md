# Руководство по настройке системы модерации и публикации новостей

## Шаг 1: Создание ботов

### 1.1 Бот модератора
1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Выберите имя для бота (например, "News Moderator Bot")
4. Выберите username (например, "news_moderator_bot")
5. Сохраните полученный токен

### 1.2 Бот издателя
1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Выберите имя для бота (например, "News Publisher Bot")
4. Выберите username (например, "news_publisher_bot")
5. Сохраните полученный токен

## Шаг 2: Создание канала

### 2.1 Создание канала
1. В Telegram нажмите на меню (☰)
2. Выберите "Создать канал"
3. Введите название канала
4. Выберите тип (публичный или приватный)
5. Добавьте описание (опционально)

### 2.2 Добавление бота издателя в канал
1. Откройте созданный канал
2. Нажмите на название канала сверху
3. Выберите "Администраторы"
4. Нажмите "Добавить администратора"
5. Найдите вашего бота издателя по username
6. Назначьте права:
   - ✅ Отправка сообщений
   - ✅ Редактирование сообщений
   - ✅ Удаление сообщений

### 2.3 Получение ID канала
1. Отправьте любое сообщение в канал
2. Перешлите это сообщение боту @userinfobot
3. Скопируйте ID канала (например, "-1001234567890")

## Шаг 3: Настройка конфигурации

### 3.1 Создание файла конфигурации
```bash
cp config_example.py config_local.py
```

### 3.2 Заполнение конфигурации
Откройте `config_local.py` и заполните:

```python
# Конфигурация для бота модератора
MODERATOR_BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"  # Ваш токен бота модератора

# Конфигурация для бота издателя
PUBLISHER_BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"  # Ваш токен бота издателя
CHANNEL_ID = "@your_channel_name"  # ID вашего канала

# Дополнительные настройки
PUBLISH_INTERVAL_SECONDS = 300  # Интервал публикации (5 минут)
MODERATION_TIMEOUT_SECONDS = 1800  # Таймаут модерации (30 минут)
```

## Шаг 6: Использование

### 6.1 Команды бота модератора
- `/start` - регистрация в системе
- `/moderator` - получение прав модератора
- `/stats` - просмотр статистики
- `/publish` - ручная публикация новостей

### 6.2 Workflow работы
1. **Добавление новости**: Внешний источник → База данных
2. **Модерация**: Бот отправляет новость модераторам → Кнопки одобрения/отклонения
3. **Публикация**: Одобренная новость автоматически публикуется в канал

## Устранение неполадок

### Проблема: "Token is invalid!"
**Решение**: Проверьте правильность токена бота

### Проблема: "chat not found"
**Решение**: Убедитесь, что бот добавлен в канал как администратор

### Проблема: "Forbidden: bot was blocked by the user"
**Решение**: Пользователь заблокировал бота, попросите разблокировать

### Проблема: "Bad Request: chat not found"
**Решение**: Проверьте правильность ID канала
