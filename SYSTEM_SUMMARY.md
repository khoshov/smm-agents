## 🚀 Как использовать

### 1. Быстрый старт
```bash
# Применение миграций
alembic upgrade head

# Запуск системы
python run_system.py
```

### 2. Тестирование
```bash
# Тест публикации

# Финальный тест системы

```

- `/start` - регистрация в системе
- `/moderator` - получение прав модератора
- `/stats` - просмотр статистики
- `/publish` - ручная публикация новостей
