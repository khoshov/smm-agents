Проблема с callback'ами была успешно исправлена. Теперь бот корректно обрабатывает нажатия на кнопки "Опубликовать" и "Отклонить".

4. **Обработка Ctrl+C** - добавлена graceful shutdown для корректной остановки бота

## Как это работает

1. **Запуск бота** - бот запускается в фоновом режиме
2. **Отправка новости** - новость отправляется всем модераторам с кнопками
3. **Модерация** - модераторы нажимают "Опубликовать" или "Отклонить"
4. **Результат** - функция возвращает результат модерации

## Обработка Ctrl+C

Теперь бот корректно обрабатывает Ctrl+C:

1. **Graceful shutdown** - бот плавно останавливается
2. **Отмена всех задач** - все фоновые задачи корректно завершаются
3. **Очистка ресурсов** - соединения с базой данных и Telegram API закрываются

### Пример работы:
```bash
python test_ctrl_c.py
# Нажмите Ctrl+C в любой момент
# Вы увидите: "🛑 Получен Ctrl+C!" и "✅ Бот успешно остановлен"
```

## Формат callback данных

Правильный формат callback данных:
- `news_{news_id}_approve` - для одобрения
- `news_{news_id}_reject` - для отклонения

Где `{news_id}` - это ID новости, который может содержать подчеркивания.
